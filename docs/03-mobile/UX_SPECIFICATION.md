# NIRVAN — Mobile UX Specification

## 1. UX Goal

Create a calm, accessible patient experience for rehabilitation and wellbeing.

The app should work for users with:

- Limited digital literacy
- Reduced mobility
- Older age
- Visual limitations
- Cognitive load challenges

## 4. Home

Show only the most important daily actions.

```text
Good Morning

Today's Recovery
[Start next activity]

Exercise     2 remaining
Medication   3/4
Wellbeing    Check-in
Progress     82%
```

## 5. Recovery

Sections:

- My Plan
- Exercises
- Functional Activities
- Mobility
- Speech
- Cognitive
- Breathing
- Milestones

Only relevant modules should appear for the selected pathway.

## 7. Wellbeing

- Mood
- Sleep
- Energy
- Fatigue
- Nutrition education
- Mindfulness
- Lifestyle

## 8. Progress

Use simple trends:

- Sessions
- Consistency
- Goals
- Walking/activity
- Selected health metrics

Avoid overwhelming users with raw medical data.

## 9. Learn

- Condition guides
- Exercise education
- Articles
- Videos
- FAQs
- News

## 10. Profile

- Personal information
- Recovery conditions
- Goals
- Connected health platforms
- Medication
- Notifications
- Language
- Accessibility
- Privacy
- Data export
- Delete account

## 11. Accessibility

Minimum requirements:

- Large touch targets
- Dynamic text support
- Screen reader labels
- High contrast
- Captions
- Audio instructions
- Reduced motion
- Clear error states
- No color-only status indicators

## 12. UX States

Every major screen needs:

- Loading
- Empty
- Error
- Offline
- Success
- Permission denied

## 13. Design Principle

The user should always know:

1. Where am I?
2. What should I do next?
3. Why does it matter?
4. What happens after I complete it?
