# NIRVAN — Development Plan

## 1. Development Strategy

Build the smallest useful recovery loop first.

```text
Patient
 ↓
Goal
 ↓
Recovery Plan
 ↓
Exercise
 ↓
Daily Check-in
 ↓
Progress
```

AI, computer vision and advanced integrations come later.

## 12. Definition of Done

A feature is done when:

- Requirements implemented
- UX states implemented
- Unit tests pass
- Integration tests pass
- Accessibility reviewed
- Security reviewed
- Offline behavior tested where applicable
- Analytics event documented
- Crash monitoring verified
- Documentation updated
