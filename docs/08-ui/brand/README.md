# NIRVAN Brand Assets

This folder contains the NIRVAN compact mark, logo lockup, app icons, and social-share visuals aligned with the website UI palette.

| Asset | Dimensions | Intended use |
| --- | ---: | --- |
| `icon-1024.png` | 1024×1024 | PNG master compact mark for app icons and small UI use |
| `nirvan-logo-lockup.png` | 1920×1920 | Full logo lockup reference and spacious brand placements |
| `nirvan-app-icon-1024.png` | 1024×1024 | Master icon for future iOS/Android packaging |
| `icon-512.png` | 512×512 | Installable web-app icon |
| `icon-192.png` | 192×192 | Installable web-app icon |
| `apple-touch-icon.png` | 180×180 | Apple touch icon |
| `nirvan-social-portrait-full-hd.png` | 1080×1920 | Portrait social or story creative |
| `nirvan-social-landscape-full-hd.png` | 1920×1080 | Open Graph, social-share, and landscape brand creative |

The website uses `/brand/nirvan-social-landscape.png` as the Open Graph and Twitter image. It is the 1920×1080 landscape asset. The web manifest references the 192×192 and 512×512 icons, while Next.js App Router uses `src/app/icon.png` and `src/app/apple-icon.png` for browser and Apple icon discovery. All logo, favicon, and app-icon deliverables in this asset set are PNG-based.

The compact PNG mark uses **Deep Forest** `#436444`, **Warm Cream** `#FDF9F3`, and a small **Warm Clay** `#C0564B` accent. It is intentionally a simple inclusive brand mark and should not be presented as religious instruction or as a claim that NIRVAN is equivalent to Buddhist nirvana.
